# DeepNorthCompat

This is a Valheim mod for a personal Valheim modpack.

It currently fixes bugs and incompatibilities involving:

- ImpactfulSkills and AzuCraftyBoxes quality-aware ingredient selection and consumption.
- ImpactfulSkills bow stamina scaling and tooltip reporting.
- SeaAnimals and AirAnimals custom creature drop ranges.
- AzuEPI 2.6.1 inventory character preview, which restarted its animation whenever a nearby creature or player changed equipment.

The AzuEPI fix applies only to version 2.6.1. Other AzuEPI builds keep their original behavior. [The diagnosis](https://github.com/TalXVI/DeepNorthCompat/blob/main/docs/azu-epi-preview.md) has the details.
